# 마음AI 예시 형식 대응표 · 임시안

참고 원본: `[AI Expo] 2025 AI Expo HomeIoT 데이터 시트.xlsx`. 사진관 v09도 기능 설명, 한국어 학습, 평가 시트를 분리하고 `<maum_#>(인자)<maum_end>` 표기를 쓴다.

| 임시 토큰 | 기능 | 인자값 | 예시 출력 |
| --- | --- | --- | --- |
| `<maum_0>` | 배치 선택 | `layout=1` 한 장, `layout=2` 네 컷 | `<maum_0>(layout=2)<maum_end>` |
| `<maum_1>` | 프레임 선택 | `frame=1` 기본, `2` 별빛, `3` 파티, `4` 별곰이 | `<maum_1>(frame=2)<maum_end>` |
| `<maum_2>` | 타이머 설정 | `seconds=3`, `10`, `15`, `20` | `<maum_2>(seconds=10)<maum_end>` |
| `<maum_3>` | 사진 촬영 | 인자 없음. 현재 설정 사용 | `<maum_3>()<maum_end>` |
| `<maum_4>` | 실행 보류 | `reason=1` 불명확, `2` 미지원, `3` 다중 동작 | `<maum_4>(reason=1)<maum_end>` |
| `<maum_5>` | 네 컷 촬영 방법 | `view=1` 네 칸에서, `2` 한 컷씩 크게 | `<maum_5>(view=2)<maum_end>` |
| `<maum_6>` | 화면 구도 조절 | `adjustment=1` 확대, `2` 축소, `3` 왼쪽, `4` 오른쪽, `5` 위, `6` 아래, `7` 초기화 | `<maum_6>(adjustment=3)<maum_end>` |

토큰 번호·인자값과 실행 보류의 함수화는 사진관용 **제안안**이다. 마음AI가 확정한 사양이 아니며 코드 수령 뒤 확인해야 한다. 학습 시트의 `번역` 열에는 한국어 발화가 있고, 평가 시트의 `Query(영문)`은 공란이다. 모든 예시는 사람 검수 전이다.
