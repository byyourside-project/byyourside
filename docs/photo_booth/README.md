# 음성 조작 무인 포토존

작성일: 2026-10-17. 이 폴더는 사진관 앱의 요구사항, 데이터 설계, 학습·검증 결과를 정리한다. 요구사항과 데이터셋은 팀·교수·마음AI 검토 전 초안이며, Llama 3.2 1B의 PC 학습·검증은 별도로 완료했다.

## 이번 단계의 결정

- 사용자: 카메라·조작 화면과 떨어진 행사 포토존의 촬영 위치에서, 혼자 또는 일행과 짧은 한국어 음성 명령으로 사진을 찍으려는 사람.
- 시연 범위: PC 카메라 미리보기, 1장/4컷 배치, 기본/별빛/파티/별곰이 프레임, 3/10/15/20초 타이머 설정, 화면 구도의 1.00~2.00배 확대·상하좌우 이동·초기화, 현재 설정으로 사진 촬영. 촬영 결과는 앱이 자동 표시한다. 실제 카메라 본체는 움직이지 않는다.
- 입력 1회에 기능 1개. 여러 기능을 한 번에 요구하거나 뜻이 불명확하면 촬영을 실행하지 않고 다시 말해 달라고 안내한다.
- LLM은 음성 인식 결과를 `기능 + 설정값`으로 바꾼다. 카메라 촬영, 프레임 적용, 타이머 상태 관리와 촬영 결과 자동 표시는 앱이 담당한다.
- 재촬영·결과 보기·저장·인쇄·결제·QR 공유·얼굴 보정 음성 명령은 첫 시연 범위에서 제외한다.

## 순서와 산출물

1. [요구사항 정의](requirements.md)의 설치 장면·범위·성공 기준을 팀에서 확정하고, 변경된 주제를 교수·멘토에게 알린다. [프로젝트 계획서](project_plan.md)에 순서와 산출물을 정리했다.
2. [기능·데이터 설계](data_design.md)의 명령 경계와 인자값을 확정한다.
3. [마음AI 예시 형식 Excel v09](../../outputs/photo_booth/음성포토존_마음AI형식_검수전_v09.xlsx)과 [JSON 원본](dataset_v09_draft.json)의 문장·정답을 사람이 검수한다. 현재 학습 1,280개, 검증 256개, 최종 시험 256개의 자동 생성 초안이다. [토큰·인자 대응표](maum_format_mapping.md)의 번호와 값은 임시안이다.
4. PC 포토존 기능을 버튼으로 먼저 구현한 후, STT와 모델의 함수 출력을 연결한다.
5. 마음AI가 공유할 학습·평가 코드/토크나이저 형식에 데이터를 변환해 학습하고 평가한다.
6. 오류 분석 후 데이터/설정을 한 번에 한 종류씩 수정하고 **같은 평가셋**으로 비교한다. 마지막에는 손대지 않은 시험셋을 별도로 측정한다.
7. 학생 팀이 안내받은 범위의 모델 변환을 진행한다. 양자화는 마음AI 담당이며, 변환의 구체적 종료 지점은 코드 공유 시 확인한다.

## 현재 상태

Android 보드의 실제 카메라·마이크·스피커 시험과 실패 원인, 직접 USB 접근으로 성공한 방법, 재부팅 후 실행 절차는 [보드 USB 장치 시행착오·인수인계](BOARD_USB_DEVICE_TEST.md)에 기록했다. 현재 펌웨어에서는 기본 카메라/일반 오디오 앱 경로에 문제가 있어 USB 직접 접근을 시험했으며, 기존 웹 포토부스에 통합한 상태는 아니다.

PC 시연 앱은 [포토존 화면](../../web/photo_booth/index.html)으로 구현했다. 프로젝트 루트에서 `python3 scripts/run_photo_booth.py`를 실행하고 `http://127.0.0.1:8770/`을 열면 된다. 카메라·화면과 촬영 위치가 떨어진 행사 포토존을 가정하며, 앱 화면에는 미리보기를 크게 둔다. 네 컷을 선택하면 촬영 전부터 완성본 모양의 네 칸이 보인다. 네 칸 안에서 한 장씩 찍거나, 촬영 중에는 카메라 화면을 크게 보고 한 장씩 찍는 방법을 선택할 수 있다. 각 컷마다 설정한 시간(최소 3초)을 기다리며, 마지막에 완성된 세로 사진 띠를 표시한다. 카메라 접근을 허용한 뒤 배치·프레임·타이머·촬영 방법을 고르고 촬영할 수 있다. `전체 화면` 버튼은 발표 시연용이다. 브라우저가 음성 인식을 제공하면 `말하기` 버튼을 사용할 수 있고, 그렇지 않으면 문장 입력·화면 버튼으로 조작한다. 현재 문장 해석은 **기존 키워드 / 학습 모델**을 선택할 수 있다. `--model-adapter`로 학습 결과 폴더를 지정하면 STT 문장 전체를 학습한 Llama 모델이 해석한다. 연결 방법과 확인 동작은 [모델 연결 문서](model_integration.md)를 참고한다. 마음AI의 최종 모델 연결은 아니다. 촬영 이미지는 현재 페이지 메모리에서만 결과로 표시하고 파일로 저장하지 않는다. 실제 촬영 거리와 원거리 음성 인식은 아직 검증하지 않았다.

화면 구도 조절은 소프트웨어에서 영상을 잘라 확대하는 방식이다. 확대·축소는 0.25배씩 1.00~2.00배, 위치 이동은 확대 상태에서만 가능하다. 버튼 또는 “화면 확대해 줘”, “왼쪽으로 옮겨 줘”, “구도 초기화해 줘” 같은 문장으로 시험할 수 있다. 촬영 결과에도 같은 구도 값을 적용한다. v09 데이터 초안에는 구도 조절 7종을 각각 학습 40개, 검증 8개, 시험 8개씩 포함했다.

`seed_examples.json`은 기존 70개 원본이며, v09는 이를 포함해 자동 확대한 **가상 문장 초안**이다. v09 Excel은 마음AI HomeIoT 예시의 핵심 시트와 `<maum_#>(...)<maum_end>` 표기법을 따른다. 포토존 함수의 토큰 번호, 인자값, `no_action` 처리법과 학습 코드의 실제 열 요구사항은 멘토 자료가 오면 대조해야 한다. 목표 Llama 3.2 1B 모델의 GPU 전체 1회 학습과 검증은 완료했다. 검증 193/256(75.39%)이며 [GPU 결과](GPU_PC_RESULT.md)에 기록했다. 사람 검수, 마음AI 최종 STT·LLM 연동, QCS6490 변환과 양자화는 아직 수행하지 않았다. 합성 텍스트 검증 결과를 실제 음성 환경 정확도로 해석해서는 안 된다.

[v09 데이터 점검 보고서](dataset_v09_review.md)는 수량·형식 검사와 남은 위험을 기록한다. Excel을 수정해도 JSON 초안은 자동으로 갱신되지 않는다. 검수 후 하나를 확정 원본으로 삼고 나머지를 다시 내보내야 한다.

## 마음AI에 확인할 인터페이스

마음AI 코드 없이 진행한 [로컬 학습 시험 기록](local_training.md)을 별도로 남겼다. 작은 공개 모델로 토큰 등록·2단계 학습·평가 코드 실행을 확인했으며, 목표인 Llama 3.2 모델은 접근 권한이 없어 아직 학습하지 못했다.

- 최종 함수 이름·토큰 번호·종료 토큰·허용 인자 형식과 `실행 불가` 정답의 표현
- 학생 학습 환경과 기본 모델 접근 방법, 보드용 변환 작업의 정확한 범위
- 양자화용 보정 데이터의 전달 방식과 양자화 후 재평가 방법

참고: 마음AI 특강1(데이터 기획), 특강2(LLM), 특강3(양자화/Agent). 다른 팀의 데이터 양과 학습 성능은 이 주제의 목표 수치로 옮겨 쓰지 않는다.
