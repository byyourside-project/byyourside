## 자동 점검 결과

- 1,400행 모두 Excel과 JSON의 발화·순서가 일치한다.
- 전체 발화의 **완전 중복 0개**. 학습·검증·시험 간 완전 중복도 0개다.
- 모든 출력은 임시 `<maum_0>`~`<maum_5>`와 `<maum_end>` 형식을 만족한다.
- 금지하기로 한 정확한 발화 “네 컷으로 찍어줘”, “삼 초 뒤에 찍어줘”, “다시 찍어줘”는 없다.
- 각 기능·인자값별 수량을 맞췄다. 이 검사는 라벨의 의미적 정확성이나 모델 성능을 증명하지 않는다.

## 사람 검수에서 확인할 문제

1. 같은 문장 틀에서 단어만 바꾼 예시가 많다. **뜻이 거의 같은 중복**과 학습·검증·시험 사이의 문장 틀 유사성은 아직 해결하지 못했다. 실제 사용자가 말할 법한 발화로 교체해야 한다.
2. “기본 디자인”, “사진 네 장 구성” 같은 표현의 의미가 명확한지, 조사·어순이 자연스러운지 확인한다.
3. `capture_photo`가 아닌 설정 요청에서 셔터가 눌리지 않는지, 지원하지 않는 기능과 복합 명령이 `no_action`으로 올바르게 분류됐는지 확인한다.
4. 촬영 위치·거리·행사 소음을 정하고 실제 음성을 시험해야 한다. 현재 문장은 텍스트 초안이며 STT 오류나 소음 데이터를 담지 않았다.
5. 마음AI가 제공할 모델·토크나이저·학습 코드에 맞춰 임시 토큰 번호와 `no_action` 출력, 열 형식을 최종 대조한다.

따라서 **1,400개를 검수 완료 학습 데이터나 성능 개선 결과로 보고하면 안 된다.** 실제 모델 학습과 평가도 아직 실시하지 않았다.
