# 음성 조작 무인 포토존 요구사항 정의서 v0.7

작성일: 2026-10-17 · 상태: 팀 검토용 초안

## 해결할 문제와 설치 조건

학교 축제·행사장 같은 무인 포토존에서 **카메라와 조작 화면이 촬영 위치와 떨어져 있으면**, 이용자가 설정을 바꾸거나 셔터를 누르기 위해 포즈를 잡은 자리를 떠나야 한다. 단체 사진에서는 모두 자리를 잡은 뒤 화면을 조작할 사람이 남지 않을 수도 있다. 촬영 위치에서 한국어 음성으로 설정과 촬영을 조작하게 하되, 화면 버튼은 대체 조작 수단으로 유지한다.

화면이 바로 옆에 있는 좁은 사진관 부스에는 이 문제가 약하다. 따라서 조작 화면과 촬영 위치가 떨어진 **무인 포토존**을 주요 사용 환경으로 삼는다. 실제 설치 거리·마이크 위치·예상 소음은 시연 장소를 정한 뒤 확정한다.

## 목표와 사용자 흐름

행사 무인 포토존에서 사용자가 촬영 위치를 떠나지 않고 짧은 음성 명령으로 배치, 프레임, 타이머와 네 컷 촬영 방법을 각각 설정하고 사진을 촬영한다.

1. “네 컷 배치로 바꿔줘” → 화면 배치만 변경한다.
2. “별곰이 프레임으로 바꿔줘” → 사진 테두리와 캐릭터 장식만 변경한다.
3. “타이머를 십 초로 설정해 줘” → 대기 시간만 변경한다.
4. 네 컷일 때 “한 컷씩 크게 찍어줘” → 촬영 방법만 큰 화면 방식으로 바꾼다.
5. “사진 찍어줘” → 현재 배치·프레임·타이머·촬영 방법 설정으로 촬영한다. 한 장 배치는 1장, 네 컷 배치는 4장 촬영한다.
6. 촬영 완료 뒤 사진은 화면에 자동 표시한다. 결과 보기·저장·재촬영 음성 명령은 제공하지 않는다.

## 학습할 기능

| 기능 | 허용값과 동작 |
| --- | --- |
| 배치 선택 | 한 장 또는 네 컷. 촬영은 시작하지 않음 |
| 프레임 선택 | 기본, 별빛, 파티, 별곰이. 미리보기와 촬영 결과에 장식 적용. 촬영은 시작하지 않음 |
| 타이머 설정 | 3초, 10초, 15초, 20초.  촬영은 시작하지 않음 |
| 네 컷 촬영 방법 | 네 칸 안에서 한 장씩 촬영하거나, 카메라를 크게 보며 한 장씩 촬영. 네 컷 배치에서만 적용 |
| 화면 구도 | 1.00~2.00배로 확대·축소, 확대한 화면의 보이는 위치를 상하좌우로 이동, 초기화. 실제 카메라 본체는 움직이지 않음 |
| 사진 촬영 | 현재 설정을 사용해 촬영. 시간 인자 없음 |
| 실행 보류 | 불명확·미지원·여러 동작 요구이면 실행하지 않고 안내 |
| 대체 입력 | 음성 인식이 실패해도 화면 버튼과 문장 입력으로 같은 기능을 조작 |

“네 컷으로 찍어줘”, “삼 초 뒤에 찍어줘”, “다시 찍어줘”는 이번 학습 데이터에서 제거한다. 배치·타이머 설정과 촬영을 한 문장으로 합치지 않는다. 재촬영, 결과 보기, 저장 기능은 범위에서 제외한다.

## 시연·검증 기준

- 미리보기에 현재 배치·프레임·타이머를 보여 준다. 네 컷 배치를 선택하면 촬영 전부터 네 칸짜리 완성본 구도가 보인다. ‘네 칸에서 찍기’는 현재 칸에 카메라 영상과 카운트다운을 보여 주며 촬영된 칸을 채운다. ‘한 컷씩 크게 찍기’는 촬영 중 카메라 화면 전체에 한 컷씩 보여 주고 각 컷을 촬영한다. 두 방법 모두 촬영 완료 시 같은 세로 사진 띠를 표시한다.
- 모델 출력은 허용 기능·인자값을 검사한 뒤에만 실행한다. 카운트다운 중 중복 촬영을 막는다.
- 촬영은 명시적인 촬영 명령 또는 화면 촬영 버튼으로만 시작한다. 설정 명령, 불명확·미지원 명령으로는 셔터가 눌리지 않아야 한다.
- 화면 구도를 조절하면 미리보기와 촬영 이미지에 같은 확대·이동 설정을 적용한다. 1.00배에서는 이동을 막고, 확대·이동만으로 촬영을 시작하지 않는다.
- 텍스트 모델 평가에서는 기능 일치율, 값 일치율, 전체 정답률을 구분한다. 음성 시연에서는 설정 4종과 촬영의 실제 동작을 확인한다.
- 사진의 임시 보관·삭제 방법은 구현 전에 정한다. 영구 저장 명령은 이번 범위에 없다.
- 마음AI 학습 코드와 토큰 사양을 받기 전까지 데이터시트는 임시 초안이다. 모델 성능은 아직 측정하지 않았다.

## 확정해야 할 사항

- 실제 시연 장소의 촬영 위치·카메라·조작 화면·마이크 배치와 예상 소음
- 네 컷 촬영 중 안내 방식, 결과 표시 시간, 임시 사진 삭제 시점
- 원거리에서 말한 음성이 얼마나 정확히 전사되는지 별도 측정할 방법
- 마음AI 모델·토큰 사양과 QCS6490 보드 변환의 정확한 범위

현재 PC 앱은 브라우저 음성 인식과 규칙 기반 문장 해석을 사용하는 시연이다. 실제 모델 성능, 오프라인 동작, 개인정보 보호 효과는 아직 검증하지 않았다. v09 데이터 초안에 화면 구도 명령 7종을 추가했으며, 학습 전에 사람 검수와 마음AI 토큰 형식 확인이 필요하다. 원거리 발화·소음 상황을 반영한 검증 사례도 필요하다.
