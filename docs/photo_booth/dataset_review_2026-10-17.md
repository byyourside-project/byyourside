# 사진관 학습 데이터 3차 구조 검수

작성일: 2026-10-17. 범위: `seed_examples.json`과 같은 자료로 만든 마음AI 예시 형식 Excel v07. 데이터 구조 검사이며 모델 성능 평가가 아니다.

| 기능 | 학습 후보 | 평가 후보 |
| --- | ---: | ---: |
| 배치 선택 | 8 | 4 |
| 프레임 선택 | 12 | 4 |
| 타이머 설정 | 12 | 4 |
| 네 컷 촬영 방법 | 6 | 2 |
| 사진 촬영 | 6 | 3 |
| 실행 보류 | 6 | 3 |
| **합계** | **50** | **20** |

재촬영·결과 보기·저장 함수와 해당 긍정 예시를 제거했다. 촬영 명령에서 지연 시간 인자를 제거하고 별도 타이머 설정 함수로 옮겼다. “네 컷으로 찍어줘”, “삼 초 뒤에 찍어줘”, “다시 찍어줘”도 데이터에서 삭제했다. 새 정답은 기능 하나와 허용 인자 하나 이하로 제한한다.

모든 발화는 작성자가 만든 가상 문장이고 사람 검수 전이다. 발화 70개의 공백 제외 완전 중복은 0건이다. 학습·평가 발화 간 최대 글자 유사도는 0.80으로, 0.85 이상 경보는 없었다. 다만 의미상 가까운 표현의 누수는 사람 검수가 필요하다. 출력 토큰 형식과 Excel 행 수(학습 50개, 평가 20개)를 재검사했다. 실제 모델 학습과 정확도 측정, 보드 변환과 양자화는 아직 하지 않았다. PC 카메라 시연은 구현됐으나 음성 명령은 현재 브라우저 음성 인식과 규칙 기반 해석을 사용한다. 특히 `no_action` 함수 형식은 멘토 코드와 대조해야 한다.
