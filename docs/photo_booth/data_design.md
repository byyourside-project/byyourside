# 싱글턴 기능 호출 데이터 설계 v0.7

한 행은 **한국어 사용자 발화 한 번 → 함수 출력 하나**다. 작은 원본 70개는 `seed_examples.json`에 보존했다. 확대 초안은 [JSON](dataset_v09_draft.json)과 [마음AI 예시 형식 Excel v09](../../outputs/photo_booth/음성포토존_마음AI형식_검수전_v09.xlsx)이며, 생성 절차는 `scripts/build_photo_dataset.py`에 있다. 토큰 번호와 인자값은 [임시 대응표](maum_format_mapping.md)에 적었다.

| action | 인자 | 판단 기준 |
| --- | --- | --- |
| `select_layout` | `layout=single|four_cut` | 배치만 설정 |
| `set_frame` | `frame=plain|starlight|party|buddy` | 사진 테두리·장식만 설정 |
| `set_timer` | `seconds=3|10|15|20` | 타이머만 설정 |
| `set_shooting_view` | `view=strip|full` | 네 컷 촬영 방법만 설정. 네 컷 배치에서만 유효 |
| `adjust_view` | `adjustment=zoom_in|zoom_out|move_left|move_right|move_up|move_down|reset` | 화면 확대·축소, 상하좌우 구도 이동, 초기화. 촬영은 시작하지 않음 |
| `capture_photo` | 없음 | 현재 설정으로 촬영 시작 |
| `no_action` | `reason=ambiguous|unsupported|multi_action` | 실행하지 않고 안내 |

타이머는 앱 상태로 보관하며 촬영 함수에는 시간 인자를 주지 않는다. “십 초로 타이머 맞춰 줘” 다음 “사진 찍어줘”처럼 두 번 말하는 흐름이다. 촬영 후 결과는 앱이 자동 표시한다. 재촬영·결과 보기·저장은 학습할 기능이 아니다.

한 발화에 배치 변경과 촬영이 함께 있으면 `multi_action`으로 분류한다. “네 컷으로 찍어줘”, “삼 초 뒤에 찍어줘”, “다시 찍어줘”는 이번 후보 데이터에서 삭제했으므로 모델이 이 문장들에 정확히 어떻게 반응할지는 평가하지 않는다. 음성 인식 결과의 숫자·띄어쓰기 변형은 실제 수집 후 추가한다.

학습과 평가 발화는 분리한다. 모델 학습 전에는 출력 형식 적합률과 정확도를 **미측정**으로 보고한다. 데이터를 바꾼 뒤 성능을 비교할 때는 같은 평가셋을 사용하고, 최종 시험셋은 따로 마련한다.

## 데이터 확대 목표(팀 검토용)

기존 50개 학습·20개 평가 문장을 바탕으로 **학습 1,280개·검증 256개·최종 시험 256개**의 자동 생성 초안을 만들었다. 마음AI HomeIoT 예시의 시트에는 수백~수천 행이 있다. 이 수량은 **검수 완료 건수나 성능을 보장하는 최소 개수가 아니다.** 문장과 정답 라벨을 사람이 검수하고 실제 학습 오류에 따라 조정한다.

- 배치·프레임·타이머·촬영 방법의 **허용값마다** 명령형, 질문형, 짧은 구어체, 조사·띄어쓰기 변형을 만든다. 의미가 같은 문장의 단순 복제로 수량을 채우지 않는다.
- `capture_photo`와 `no_action`을 충분히 포함한다. 특히 설정 요청이 촬영으로 오인되는 경우, 지원하지 않는 저장·재촬영 요청, 복합·불명확 명령을 별도로 검토한다.
- 촬영 위치에서 실제로 말할 법한 표현을 팀원이 수집·작성하고, 작성자 외 사람이 **발화와 정답 기능·값을 함께 검수**한다. 원거리 발화의 STT 오인식은 실제 시험 결과를 얻은 뒤 별도 사례로 보강한다.
- 문장 틀이나 거의 같은 표현이 학습·검증·시험에 나뉘어 들어가지 않게 분할한다. 검증셋은 수정 전후 비교에 고정하고, 시험셋은 최종 확인 때만 사용한다.
- 각 기능·값별 건수, 중복, 오라벨, 실행하면 위험한 오촬영 사례를 집계한다. 생성 초안과 검수 완료 데이터를 구분해 기록한다.

무인 포토존으로 사용 장면을 바꿔도 위 명령의 기능·인자값은 유지한다. 다만 **촬영 위치에서 멀리 말한 음성이 제대로 전사되는지**는 텍스트 LLM 평가와 다른 문제다. 실제 설치 거리·소음에서 STT 전사와 최종 실행을 별도로 점검하고, 그 결과를 보고 발화 예시와 실패 사례를 보강한다.

PC 앱과 v09 데이터 초안에 화면 구도 조절 7종을 추가했다. 각 값에 학습 40개·검증 8개·시험 8개의 합성 문장을 넣었다. 이는 고정 카메라 영상의 보이는 범위를 바꾸며 카메라 본체를 움직이지 않는다. 이동은 확대 중에만 가능하고 배율은 1.00~2.00배 범위에서 0.25배씩 변한다. 앱의 경계 동작은 데이터셋과 별도로 확인한다. 토큰 형식은 마음AI 자료 수령 후 재확인한다.
