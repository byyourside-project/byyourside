# v09 데이터 점검 보고서 · 검수 전

작성일: 2026-10-17. [JSON 원본](dataset_v09_draft.json)과 [마음AI 예시 형식 Excel](../../outputs/photo_booth/음성포토존_마음AI형식_검수전_v09.xlsx)은 같은 자동 생성 초안을 담는다. 이전 초안의 명령에 화면 구도 조절 기능을 추가했다.

| 구분 | 학습 | 검증 | 최종 시험 | 합계 |
| --- | ---: | ---: | ---: | ---: |

| 화면 구도 조절 7종 | 280 | 56 | 56 | 392 |
| v09 합계 | 1,280 | 256 | 256 | 1,792 |

새 기능은 확대, 축소, 왼쪽·오른쪽·위·아래 이동, 초기화이며 각 값마다 학습 40개·검증 8개·시험 8개다. Excel 출력은 임시 `<maum_6>(adjustment=1..7)<maum_end>` 형식이다. 번호와 값은 마음AI가 확정한 사양이 아니다.

## 확인한 것과 남은 문제

- 생성 스크립트에서 분할별 수량과 발화 문자열의 완전 중복 부재를 검사한다. Excel에는 기능 설명, 학습, 검증, 최종 시험 시트가 있다.
- 새 문장은 사람이 직접 수집한 발화가 아니라 정형 문장의 표현을 바꾼 합성 초안이다. 분할 간 완전 중복이 없어도 문장 틀이 비슷하다. 이 자료만으로 일반화 성능을 주장할 수 없다.
- `adjust_view`는 한 번에 한 단계 조절하는 명령이다. 실제 배율·이동 한계, 1.00배일 때 이동 불가, 촬영 중 동작은 앱에서 별도로 검증해야 한다.
- 사용자가 말한 카메라 상하좌우 이동은 화면 속 보이는 범위 이동으로 구현했다. 물리적 카메라 방향 조절 데이터는 넣지 않았다.
- 사진 저장·재촬영·결과 다시 보기 명령은 지원하지 않는다. 명령 뜻이 겹치는 사례, 실제 행사 소음에서 발생한 전사 오류, 사람 검수 결과를 다음 판에 반영한다.
- 팀의 임시 토큰 사양으로 Llama 3.2 1B를 1회 학습했다. 합성 검증 문장 256개 중 193개가 완전 일치했다. 최종 시험과 실제 음성 환경 정확도는 미측정이다. [GPU 학습 결과](GPU_PC_RESULT.md)를 참고한다.
