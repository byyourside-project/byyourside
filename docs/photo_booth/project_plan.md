# 음성 조작 무인 포토존 프로젝트 계획서 v0.1

작성일: 2026-10-17 · 상태: 팀 검토용 초안 · 주차별 날짜: 학교/멘토 일정 확인 후 배정

## 목표와 발표 장면

행사장 무인 포토존에서 이용자가 **촬영 위치를 떠나지 않고** 배치, 프레임, 타이머, 네 컷 촬영 방법과 화면 구도를 음성으로 고르고 사진을 찍는다. 시연에서는 카메라와 조작 화면이 떨어진 상황을 보여 준다. 일반 사진관 부스의 가까운 터치 화면을 음성으로 대체한다는 설명은 사용하지 않는다.

## 검증 방법

- **기능:** 배치 2종, 프레임 4종, 타이머 4종, 네 컷 촬영 방법 2종, 화면 구도 조절 7종을 확인한다. 각 컷의 카운트다운과 결과 순서를 확인한다.
- **음성:** 실제 촬영 위치에서 여러 문장을 말하고 전사 결과, 기능·인자 선택, 최종 실행을 나누어 기록한다. 조용한 환경과 예상 행사 소음에서 차이를 본다. 음성 파일 수집 여부와 동의 방법은 수집 전에 정한다.
- **오촬영 방지:** 불명확·미지원·복합 명령과 촬영 중 중복 요청에서 의도치 않은 셔터 작동이 없는지 확인한다.
- **모델:** 검증 256개와 최종 시험 256개는 자동 생성 초안이다. 정확한 정답과 유사 문장 누수를 사람이 확인한 뒤 고정한다. 학습 전 수치는 성능 결과로 보고하지 않는다.

## 역할과 의존 관계

- **학생 팀:** 시나리오·요구사항, 데이터 설계·검수, 제공 코드로 학습·평가, PC 앱, 안내받은 보드용 모델 변환, 발표.
- **마음AI:** 학습·평가·모델 변환 자료 공유 예정, 양자화 담당. 최종 모델·토크나이저·토큰 사양과 보드 변환의 종료 지점은 자료 수령 후 확인한다.
- **진행 조건:** 설치 장면이 정해져야 원거리 음성 검증이 의미 있다. 코드와 모델 사양이 와야 실제 학습·평가 및 보드 변환을 시작할 수 있다. PC 앱은 그 전에 검증할 수 있다.

## 지금 바로 할 일

1. 촬영 위치와 마이크·화면을 실제로 어디에 둘지 정한다.
2. [요구사항 정의서](requirements.md)의 문제와 기능 범위를 팀에서 검토한다.
3. 자동 생성한 가상 문장 1,792개와 정답을 사람이 검수하고, 원거리 발화·소음으로 생길 실패 사례를 추가한다.
4. 마음AI 자료가 오면 임시 토큰표와 Excel 열 형식을 대조한 뒤 학습 계획을 확정한다.

이 문서는 실행 순서의 초안이다. 완료 표시와 성능 수치는 실제 검증 결과가 나온 뒤 갱신한다.
