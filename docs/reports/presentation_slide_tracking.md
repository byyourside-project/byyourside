# 발표 중 문장 추적과 슬라이드 시간 안내

구현·검증: 2026-10-15 · 브랜치 `codex/script-slide-tracking`

## 변경 결과

- 기존 로컬 VAD/STT → Ollama 흐름을 유지했다. 기본 이동 후보는 현재 문장과 다음 3문장이다. 앞선 최대 2문장은 내용 확인용으로만 포함한다. 두 번 연속 미탐지 시 현재 슬라이드의 뒤쪽 문장으로 탐색을 확장한다.
- 위치 응답을 내용 일치 응답과 분리했다. 숫자 오류·부분 발화가 있어도 위치를 특정할 수 있으며, 지나온 문장은 자동 완료되지 않는다. 미일치·모호한 응답과 중복 문장의 잘못된 앞으로 이동은 보류한다.
- 실제 모델 검증에서 무관한 질문을 첫 문장으로 선택하는 응답이 발견됐다. 내용 확인은 미언급인데 위치만 선택한 모순을 차단하는 검증과 프롬프트를 추가했다. 회귀 사례로 보존했다.
- 대기 중 요청의 후보는 추론 시작 직전에 갱신한다. 이전 결과가 더 최근 위치를 덮어쓰지 않도록 발화 시각·요청 순서·수동 보정 세대를 검사한다. 계속 말하는 동안에도 유효한 처리 결과는 위치를 전진시킬 수 있다.
- `<<슬라이드 넘김>>`은 구조 정보이며 낭독 문장과 시간 배정에서 제외한다. `script_plan.slides`에 논리 슬라이드와 목표 시간을 저장한다. 내부 근거 스트림은 슬라이드 경계를 넘는 발화도 다룰 수 있도록 하나로 유지한다.
- 다음 슬라이드의 발화 시작을 자동 경계로 추정한다. 하나의 STT 구간에 두 슬라이드가 섞이거나 여러 슬라이드를 건너뛰면 시간 판단을 보류한다. 실제 자료 페이지를 조작하지 않는다.
- 이전·다음 버튼은 실제 전환 시각을 기록한다. ‘여기서 이어가기’는 위치 보정이며 다른 슬라이드로 보정했을 때 전환 시점을 확정하지 않는다.
- 목표 시간은 글자량으로 자동 배정하거나 사용자가 슬라이드별로 지정한다. 음성은 방문당 한 번, 직전 슬라이드를 얼마나 일찍/늦게 끝냈는지 안내한다. 문장마다 속도 음성을 생성하지 않는다. 마지막 슬라이드는 종료 시 정산하고 화면·기록으로 남긴다.
- 현재 문장 강조, 위치/내용 확인 비율 분리, 슬라이드별 시간표, 수동 보정, 새 3슬라이드 예제를 추가했다. 이전 문장 시간 진단 필드는 내보내기 호환성을 위해 유지한다.

| 실제 예제 WAV → SenseVoice → 로컬 LLM | 내용 확인 및 슬라이드 시간 안내 연결 통과 |
| 목표 30초 슬라이드 시간 조건 | 20초: 앞섬, 50초: 늦음, 30초: 계획 범위 |
| 실제 Yuna 음성 합성 | 앞섬/늦음 각각 약 3.87/3.84초 WAV 생성, 계획 범위에는 생성 없음 |

음성 합성은 파일로만 출력했다. 스피커 재생이나 이어폰 청취 검증으로 해석하지 않는다. 시간 조건은 통제한 입력이며 사람의 실제 발표 속도를 측정한 결과가 아니다. 브라우저에서 준비 화면과 시간표 배치를 확인했고, 입력·전환 동작은 DOM 및 앱 통합 검사로 검증했다.

로컬 모델 텍스트 사례의 요청 시간은 약 2.90~3.68초였다. 긴 문맥·복구 탐색·STT 동시 부하에서는 달라질 수 있다. 같은 실제 녹음에 대한 기존/개선 버전의 정확도 비교, 사람의 발표 위치 라벨 기준 정확도, 장시간 동시 부하, 실제 PPT/PDF 페이지 동기화는 검증하지 않았다.

재현 명령:

```bash
.venv/bin/python -m unittest discover -s tests
node tests/test_presentation_ui.cjs
.venv/bin/python scripts/validate_script_tracking.py
.venv/bin/python scripts/validate_pace_voice.py --output-dir logs/slide_pace_voice_validation
```

검증 요약과 소스 해시는 `presentation_slide_tracking_validation.json`에 저장했다. 상세 실행 기록은 `logs/script_tracking_validation.json`, `logs/slide_pace_voice_validation/dda4f762b83c/validation.json`에 있다. 사용법은 `docs/user/presentation_script_guide.md`를 참고한다.

## 실시간 속도 피드백 추가

발표 화면에 계획 대비 속도 비율, 느림·적정·빠름 게이지, 현재 슬라이드의 시간 차이와 남은 시간을 표시하는 영역을 추가했다. 100%는 계획 속도이며 75~125%를 계획 범위로 표시한다. 진행 중에는 마지막으로 확인한 발화 시점의 위치와 시간을 기준으로 계산하고, 추론 대기 중에는 직전 결과임을 표시한다. 인식 결과가 오래되거나 위치·마이크 상태가 불확실하면 속도 수치를 보류한다. 종료 후에는 마지막 슬라이드의 목표 시간과 실제 소요 시간을 표시한다.

추가 후 화면 DOM 검사 101개, JS 문법 검사와 변경 공백 검사를 통과했다. 브라우저에서 좁은 화면과 종료 상태의 배치를 확인했고 서버가 새 정적 파일을 제공하는 것도 확인했다. 이 변경은 피드백 표시를 추가하며 STT·LLM 추론 지연을 줄이지는 않는다. 위 검증 JSON의 소스 해시와 87개 DOM 검사는 피드백 영역 추가 전 검증 기록이다.
