# 발표 전 기능 구현·검증 기록

기준일: 2026-10-05. 기준 브랜치: `feat/review-history`. 대상: Windows PC에서 실행하는 발표 전 대본·영상 분석 기능. QCS6490 실측·마음AI SDK 추론·모델 변환 결과로 해석하지 않는다.

## 구현 범위

- 영상 업로드와 H.264/AAC 재생 사본 생성. 업로드 원본은 유지한다.
- TXT/MD/PDF/DOCX 대본을 읽고 화면에서 확인·수정한다.
- 기존 VAD·STT를 재사용하고, 대본과 연결된 발화의 상대 속도와 긴 쉼을 분석한다.
- 실제 MediaPipe 얼굴 모델을 CPU에서 실행해 카메라 방향을 추정한다.
- 불확실한 얼굴·눈 정보는 판단 보류하고, 분석 가능한 시간과 정면 추정 시간의 분모를 구별한다.
- 구간별 영상 이동, 전사 수정, 결과 저장, 기록 재열기·제목 변경·삭제를 연결한다.
- 마음AI 연동을 위한 측정 근거 JSON을 저장한다. 현재 SDK 호출·외부 전송은 없다.

## 검사 결과

`python -m unittest discover -s tests -p "test_review_*.py" -q`: **83개 통과**.

| 검사 | 확인한 결과 |
| --- | --- |
| 대본 파일 | 한국어 UTF-8/BOM/UTF-16/CP949, DOCX 줄바꿈·탭, 텍스트 PDF 읽기 |
| 잘못된 문서 | 빈·암호·손상 PDF, 큰 DOCX 본문, 지원하지 않는 형식 오류 처리 |
| 영상 동기화 | 2초 늦게 시작한 음성이 변환 후에도 해당 시점 유지, 무음 꼬리 구간 보존 |
| 무음 영상 | 음성 인식을 건너뛰고 말하기 속도는 판단 보류 |
| 재생·기록 | 영상 부분 요청·suffix range, 다시 열기, 전사 수정 시 원문·영상·시선 결과 보존 |
| 속도·쉼 | 대본 불일치, 영문·숫자, 짧은 구간 제외; 대본 누락을 인식 차이로 확정하지 않음 |
| 시선 규칙 | 미검출·여러 얼굴·눈 감김·경계·누락 프레임에 판단 보류 |
| 마음AI 입력 | 원문·경로·얼굴 좌표 제외, 판단 보류 유지, 임의 지시문 전달 차단 |

실제 추론 확인도 별도로 수행했다.

- Google 공식 테스트용 정면 인물 사진으로 만든 4초 영상: 얼굴 모델 실행, 정면 추정 및 분석 가능 시간 확인.
- 회색 화면 4초 영상: 시선 판단 자료 부족, 정면 비율 없음.
- 두 얼굴 4초 영상: 발표자 선택을 임의로 하지 않고 판단 보류.
- 기존 55.47초 음성을 포함한 검증용 빈 영상: 발화 9개 인식 유지, 시선 판단 보류.
- 최종 서버에서 업로드 → 영상 준비 → 분석 → 결과·`coaching_input.json` 저장 → 부분 재생 흐름 확인.
- 브라우저에서 영상·기존 음성 기록의 시간 이동과 재생 확인.

검증용 사진·영상·음성·화면 캡처는 `logs/video_validation/` 등 Git 제외 폴더에 있다. 이는 기능 연결 검사이며 실제 발표 영상의 시선·전달력 정확도 평가 자료가 아니다.

## 완료로 표시하지 않은 항목

- 실제 발표자 영상에서의 시선 오탐·미탐, 안경·조명·고개 숙임·눈만 움직이는 경우의 정확도.
- 동일하게 지나치게 빠른 발표를 판별하는 검증된 절대 속도 기준, 문장·호흡 경계의 정밀 평가.
- 마음AI 제공 SDK·모델 연결, QCS6490 모델 변환 및 보드 추론·성능 측정.
- 새 양자화 또는 자동 분석 결과를 정답으로 사용하는 모델 학습.

실제 발표 영상 검수와 보드 SDK 확보 후의 다음 작업은 `docs/user/pre_presentation.md`, `docs/deployment/qcs6490.md`에 정리했다.
