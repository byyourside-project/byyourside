# 발표 중 기능 검수와 다중 항목 후속 작업
날짜: 2026-10-04. 이전 커밋 3451bbc는 원격 main과 동기화돼 있음을 확인했다.

## 검수 수정
- 새 정정 발화의 추론이 실패해도 이전 설명됨 상태가 남는 문제가 있었다. 현재 요청이 실패하면 해당 슬라이드 항목을 판단불가로 전환한다. 근거와 이전 판단은 이벤트에 보존한다.
- 이전 revision의 실패, 다른 세션의 실패, 종료 후 실패는 상태를 변경하지 않는다.
- 타임아웃·잘못된 응답도 coaching_inference 이벤트에 outcome=error, error_type, wall_ms를 기록한다. 성공만 집계해 지연을 과소평가하지 않도록 했다.
- 설명됨·판단불가에 근거가 없거나, 미확인에 근거를 붙인 압축 응답은 어댑터에서 거절한다.

## 다음 작업 구현
단일 항목 평가 CLI를 다중 항목으로 확장했다.
사례의 모든 항목 상태와 전환 시 누락 후보를 맞혀야 사례 정답이다.
항목별 정확도와 오확인·오안내를 별도로 집계한다.
보고서 schema_version은 2이며 단일 항목의 기존 최상위 필드는 유지한다.
다중 항목 points의 정답을 모델 입력에 보내지 않는 테스트를 추가했다.

입력의 항목 ID와 문장을 짧은 사전으로 묶고, 항목별 독립 판단과 최신 정정 규칙을 보강했다.
최종 프롬프트는 semantic_v7_compact_input이다. 출력의 항목 ID와 실제 발화 근거는 유지한다.

최종 다중 항목은 20개 항목 모두 맞혔지만 2초 목표는 충족하지 못했다.
2초 제한에서는 M01(2항목), M04·M05(4항목)가 타임아웃됐다. 실패를 정답으로 계산하지 않는다.
제한 시간 측정의 p95에는 타임아웃 종료 시간도 포함되므로 실제 모델 완료 시간으로 해석하지 않는다.
새 데이터도 개발 중 사용했다. 독립·실사용 정확도나 STT+LLM 동시 성능을 증명하지 않는다.

## 슬라이드 재방문 결과 검수
슬라이드 A의 판단을 기다리다가 B로 이동하고 다시 A에서 설명을 정정하면,
이전 A 방문의 늦은 판단·타임아웃이 새 상태를 덮어쓸 수 있었다.
같은 슬라이드의 가장 최근 방문 version까지 검증하도록 수정했다.
추론 전에 오래된 방문 요청을 걸러 모델 호출을 생략하고, 추론 중 재방문한 경우에도 적용 시점에 다시 걸러낸다.
버린 요청의 pending을 해제하되 같은 방문의 더 최신 revision은 해제하지 않는다.
재방문하지 않은 다른 슬라이드의 늦은 유효한 결과는 계속 처리한다.
세션 재현 테스트 2개와 서버 큐의 불필요한 모델 호출 차단 테스트를 추가했다.
최종 전체 회귀 122개가 111.699초에 모두 통과했다. 수정한 세션·서버의 Python 컴파일과 git diff 공백 검사도 통과했다.
