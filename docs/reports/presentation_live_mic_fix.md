## 확인한 실패

- 기본 PhraseCoach에서는 최종 6개 항목 중 3개만 설명됨. STT가 성공 상태여도 전사 내용이 정확하다는 뜻은 아니다.
- 첫 슬라이드: 문장 끝이 4초 경계에서 잘리고, 조사 중복·음성 인식 오타 때문에 등록 문장 비교가 실패했다.
- 두 번째 슬라이드: 마지막 재시도의 전사가 정확했지만 `soft_max_duration` 구간으로 분류되어 다음 발화 없이 평가되지 않았다. 전환 시 판단불가로 남았다.
- 후속 짧은 발화 하나의 기록상 STT 전달 지연은 30,153ms. 원본 음성은 이 세션에 없어 정확한 원음 재인식은 불가능하다. VAD가 잘라낸 잔여 음성을 다음 발화까지 보관하는 경로가 있어 이를 수정했다. 이 수정으로 원래 녹음의 30초 지연이 사라졌다는 실측 증거는 아직 없다.

## 수정

- VAD에서 지속적인 무음이 확인되면 짧은 잔여 음성을 전달한다. 4초 제한과 샘플 보존은 유지한다.
- 음성 시간축의 무음 종료 지점을 `speech_endpoint` 이벤트로 전달한다. 이 시점 이전의 보류된 분할 전사는 다음 발화 없이 코칭으로 넘긴다. STT 결과와 종료 이벤트의 도착 순서가 달라도 처리한다.
- 무음 확인은 발화가 끝났다는 뜻이며, 설명됨 자동 승인이 아니다. 실제 내용은 코치가 판단한다.
- Ollama 응답은 `semantic_v10_named_status`: 항목별 `{"s": -1|0|1, "e": [발화번호]}`. 상태와 근거를 분리해 근거 번호가 상태 위치에 들어가는 오류를 제한한다. 프로그램에서도 상태·근거를 검증한다.
- 화면에 문장 종료 대기와 내용 판단 중 상태를 표시하고, 문장 매칭/의미 판단 모드를 명시한다.
- 기본 실행은 여전히 PhraseCoach. 이번 맥의 재시험에는 설치된 `qwen3:14b` 의미 모델과 8초 요청 제한을 명시해 실행한다. 보드용 모델 선택을 뜻하지 않는다.
