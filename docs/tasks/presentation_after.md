# 발표 후 기능 작업 계획

작성일: 2026-10-04
상태: 개발 계획. 아래 기능은 구현 완료를 의미하지 않는다.

## 목적과 현재 상태

발표 기록을 슬라이드별로 정리하고, 근거가 있는 피드백을 다음 연습의 개선 행동으로 연결한다.

현재 저장소에는 STT 원시 로그와 기술 평가 결과가 있다. 사용자용 발표 세션 리포트, 슬라이드별 결과 화면, 개선 제안은 아직 구현되지 않았다. 기술 벤치마크 보고서와 사용자 발표 피드백은 목적이 다르므로 별도 산출물로 관리한다.

## 1차 구현 범위

| 작업 | 상세 내용 | 완료 기준 |
|---|---|---|
| 세션 결과 저장 | 자료 스냅샷, 전사, 전환 시각, 판단·알림 이력 저장 | 종료 후 다시 열어 같은 결과를 확인할 수 있다. |
| 전체 결과 요약 | 실제 발표 시간, 목표 대비 차이, 주요 개선 항목 표시 | 저장된 이벤트로 계산하고 기록 누락 여부를 표시한다. |
| 슬라이드별 결과 | 목표·실제 시간, 설명된 항목, 누락 후보, 판단불가 항목 정리 | 슬라이드와 항목별 근거를 확인할 수 있다. |
| 발화 근거 조회 | 피드백에서 해당 전사와 시간 범위로 이동 | 각 판단이 참조한 구간 ID를 따라 실제 기록을 확인할 수 있다. |
| 개선 제안 | 우선 고칠 항목 2~3개와 다음 연습 방법 제시 | 실제 관찰 근거와 연결되고 실행 가능한 행동으로 작성된다. |
| 기록 품질 표시 | STT 오류·음성 손실·중단·판단불가 구간 표시 | 기록 부재를 설명 누락으로 단정하지 않고 결과의 한계를 보여준다. |

## 후속 구현 범위

- 전사 수정: 원본 전사와 사용자 수정본을 구분해 저장한다. 재분석하면 결과 버전을 새로 만든다.
- 결과 내보내기: Markdown/JSON부터 지원하고 PDF는 이후 추가한다.
- 리허설 비교: 같은 자료의 이전 실행과 시간 배분·핵심 항목 설명 상태를 비교한다.
- Q&A 결과: 질문별 답변 요약과 미해결 항목을 정리한다.
- 기록 삭제: 세션과 연결된 저장 파일을 사용자가 관리할 수 있도록 한다.
- 음성 다시 듣기: 음성 저장을 지원하는 경우 사용자 설정과 파일 수명 주기를 함께 설계한다.

## 공통 데이터와 필요한 선행 조건

- 발표 전: 당시 자료 스냅샷, 목표 시간, 슬라이드·핵심 항목 ID.
- 발표 중: 세션 시작·종료, 전환 이벤트, 전사·음성 시간 범위, 상태 변화, 실제 알림 이력.
- 결과: report_id, session_id, 결과 버전, 생성 시각, 계산 지표, 근거 구간 ID, 개선 제안.

발표 중 이벤트 계약을 먼저 합의하되, 샘플 이벤트로 저장·집계·화면 개발을 진행할 수 있다. 실제 음성이나 전체 코칭 엔진이 완성돼야만 이 단계에 착수할 수 있는 것은 아니다.

## 집계와 판단 규칙

- 슬라이드 시간은 전환 이벤트를 기준으로 계산한다. 이전 슬라이드로 돌아온 경우 각 방문 구간과 합산 시간을 구분한다.
- 필수 항목 충족률을 제공한다면 계산 가능한 항목 수와 판단불가 항목 수를 함께 표시한다.
- 미확인·누락 후보·판단불가를 구분하고 STT 손실 때문에 판단할 수 없는 항목을 확정 누락으로 표시하지 않는다.
- 발표 중 경고 이력과 종료 후 분석 결과를 구분한다. 뒤늦게 설명된 항목은 최종 상태에 반영한다.
- 숫자·약어가 포함된 전사는 원문을 보존한다. 수정이나 정규화 이력을 남긴다.
- 실제 근거가 없는 발화, 인용문, 개선 수치를 생성하지 않는다.

## 권장 작업 순서

1. 발표 전·중 담당자와 세션 및 이벤트 계약 합의.
2. 샘플 세션 데이터와 로컬 결과 저장·불러오기 구현.
3. 전체·슬라이드 시간 집계 구현.
4. 핵심 항목 결과와 발화 근거 조회 연결.
5. 결과 화면과 개선 제안 구현.
6. 실제 종료 세션을 연결하고 중단·오류 상황 검증.
7. 전사 수정·내보내기·리허설 비교 확장.

## 검증 항목

- 슬라이드 재방문, 마지막 슬라이드 종료, 중도 종료에서 시간이 올바르게 집계된다.
- 기록이 없거나 일부 손실된 세션에서도 확인 가능한 결과와 판단불가 영역을 구분한다.
- 피드백의 모든 근거 구간이 해당 세션에 존재한다.
- 자료 수정이나 전사 수정 전후의 결과 버전이 혼동되지 않는다.
- 불확실한 STT 결과가 확정적인 내용 오류나 누락으로 바뀌지 않는다.
- 리허설 비교 시 자료 버전과 비교 가능한 항목을 확인한다.

## 범위에서 제외

초기 버전에서는 평가 근거가 없는 종합 점수·순위, 표정·시선 평가, 자동 개인화 학습을 제공하지 않는다. 기술적 추론 성능을 발표자의 실력 지표로 사용하지 않는다.
