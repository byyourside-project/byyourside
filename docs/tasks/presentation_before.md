# 발표 전 기능 작업 계획

작성일: 2026-10-04
상태: 개발 계획. 아래 기능은 구현 완료를 의미하지 않는다.

## 목적과 현재 상태

발표 자료, 핵심 설명 항목, 시간 계획을 준비하고 마이크를 점검한다. 준비한 데이터는 발표 중 코칭 기준과 발표 후 분석 기준으로 재사용한다.

현재 저장소에는 Python 기반 VAD/STT와 평가 도구가 있다. 발표 준비 화면, 슬라이드 관리, 발표 세션 관리는 아직 구현되지 않았다.

## 1차 구현 범위

| 작업 | 상세 내용 | 완료 기준 |
|---|---|---|
| 발표 자료 설정 | 발표 제목, 전체 제한 시간, 슬라이드 순서·제목 입력 및 수정 | 저장 후 다시 열어 동일한 설정을 확인할 수 있다. |
| 슬라이드 핵심 항목 설정 | 슬라이드마다 반드시 설명할 항목을 수동 입력하고 필수 여부 지정 | 항목 추가·수정·삭제가 가능하며 각 항목에 고유 ID가 있다. |
| 수치·용어 기준 설정 | 핵심 수치, 단위, 고유명사, 약어와 허용 표현 입력 | 발표 중 비교에 사용할 원문과 허용 표현이 보존된다. |
| 시간 배분 | 슬라이드별 목표 시간 설정, 합계와 전체 제한 시간 비교 | 음수·0 등 잘못된 시간을 검증하고 시간 합계 차이를 표시한다. |
| 마이크 사전 점검 | 입력 장치 선택, 입력 음량 표시, 사용자가 시작하는 짧은 전사 시험 | 권한·장치 오류를 표시하고 실제 입력과 전사를 확인할 수 있다. |
| 발표 세션 시작 | 준비한 자료로 새 실행 세션 생성 | session_id와 자료 버전을 저장하고 발표 중 화면으로 전달한다. |

## 후속 구현 범위

- 리허설 모드: 실제 발표와 같은 기록·코칭 경로를 사용하되 세션 종류를 구분한다.
- PPT/PDF 불러오기: 슬라이드 순서·제목·텍스트를 추출한다.
- 핵심 항목 자동 제안: 추출된 자료를 바탕으로 항목을 제안하고 사용자가 확정한다.
- 준비 상태 확인: 빠진 핵심 항목, 시간 설정, 마이크 점검 여부를 표시한다.

자동 자료 분석은 수동 입력 흐름과 내용 코칭의 기준선이 확보된 뒤 추가한다.

## 공통 데이터와 다른 단계에 전달할 내용

- 발표 자료: deck_id, 자료 버전, 제목, 전체 제한 시간.
- 슬라이드: slide_id, 순서, 제목, 목표 시간.
- 핵심 항목: keypoint_id, 설명, 필수 여부, 기준 수치·단위·허용 표현.
- 실행 세션: session_id, 세션 종류(발표/리허설), 시작 시각, 사용한 자료의 스냅샷.

발표 중·후 담당자와 필드 이름과 단위를 먼저 합의한다. 기본 시간 단위는 초로 하고, 시각·이벤트 기록 규칙은 공통 계약에서 정한다. 과거 결과가 자료 수정으로 바뀌지 않도록 세션에는 당시 설정을 보존한다.

## 권장 작업 순서

1. 발표 자료·슬라이드·핵심 항목 데이터 계약 합의.
2. 로컬 저장 및 불러오기 구현.
3. 수동 입력·수정 화면과 시간 배분 구현.
4. 기존 STT를 연결한 마이크 점검 구현.
5. 발표 세션 생성과 발표 중 화면 연결.
6. 리허설과 자료 자동 분석 확장.

## 검증 항목

- 슬라이드 순서를 바꿔도 핵심 항목이 다른 슬라이드에 연결되지 않는다.
- 저장·재시작 후 설정이 유지되고, 과거 세션의 자료 스냅샷은 보존된다.
- 마이크 권한 거부와 장치 연결 해제를 처리한다.
- STT 실패를 마이크 점검 성공으로 표시하지 않는다.
- 핵심 항목 자동 제안을 사용하더라도 사용자 확정 상태를 구분한다.

## 범위에서 제외

실시간 누락 판단과 알림 정책은 발표 중 작업에, 결과 요약과 개선 제안은 발표 후 작업에 포함한다. 초기 버전에서는 로그인·클라우드 동기화·DB 서버를 필수로 두지 않는다.
