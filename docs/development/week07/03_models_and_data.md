## 데이터 묶음

한 묶음은 원본 영상·음성, 대본, 목표 시간, 사람이 확인한 실제 발화와 구간 정답, 촬영 조건, 검토 이력으로 구성한다. `dataset_manifest_template.csv`는 수집 목록, `annotation_example.json`은 구간 정답의 형식 예시다. 예시는 가상 자료이고 `training_eligible=false`로 둔다.

| 필드 | 형식과 의미 |
| --- | --- |
| sample_id | 자료 고유 ID |
| speaker_id / presentation_id / topic_id | 익명 화자·대본·주제 그룹 ID |
| media_file / script_file / annotation_file | 원본·대본·정답 파일의 자료 폴더 기준 상대 경로 |
| target_seconds / duration_seconds | 목표·실제 길이, 양의 초 단위 숫자 |
| speech_segments | 구간 ID, 시작·종료 초, 실제 발화, 대응 대본 ID |
| camera_segments | 시작·종료 초, 정면·아래·옆·판단 불가와 이유 |
| review_status / reviewer_id | 미검토·검토됨·수정 필요와 익명 검토자 |
| consent_scope | 보관·내부 평가·학습 등 허용 범위 |
| split / training_eligible | 미배정·학습·검증·시험, 학습 사용 가능 여부 |

## 정답 작성 기준

영상 시작을 0초로 사용하고 각 구간은 `0 <= start < end <= duration`을 만족해야 한다. 전사는 실제 들린 말을 적는다. 대본 누락과 음성 인식 오류를 구별하며, 근거가 부족하면 판단 불가로 둔다.

카메라 방향 라벨은 `front`, `down`, `side`, `unknown`으로 정의한다. 얼굴 없음·가림·여러 얼굴·조명 문제를 `unknown`의 이유에 기록한다. 방향 라벨은 실제 청중과의 눈맞춤이나 발표 품질의 정답이 아니다.

속도는 실제 발화 시각·전사 글자 수·쉼을 기록한 뒤 계산한다. 발표 전의 구간 상대 속도와 발표 중의 계획 대비 진행 속도를 분리한다. 같은 자료에서 나온 두 수치를 하나의 정답으로 합치지 않는다.

## 학습 설계

2026-10-12 추가 산출물: [마음AI 학습 데이터 시트](../../../outputs/week07_maumai/곁_마음AI_학습데이터시트_v1.xlsx)와 [데이터 설명](../../data/maumai/README.md)을 작성했다. 리뷰 24개, 대본 의미 판단 32개, 속도 문구 12개, Q&A 12개로 총 80개 가상 입력·정답을 구성했다. 시나리오 그룹 23개를 학습 후보 48행·검증 14행·시험 18행으로 나누었다. 모든 예시는 사람 검수 전이며 모델 학습은 수행하지 않았다. 예시 분할은 초기 형식 점검용이고 실제 사용자 성능 평가 자료를 대체하지 않는다.

코칭 문장용 입력은 검토된 측정 근거이며 출력은 짧은 관찰·다시 볼 구간·연습 제안이다. 근거 없는 수치·시각·종합 점수를 넣지 않는다. 발표 중 의미 판단은 대본 항목·관련 발화·현재 진행 상태와 설명됨·미확인·판단 불가 및 근거 구간을 짝지어 설계한다. 아직 말할 차례가 오지 않은 항목을 확정 누락으로 학습시키지 않는다.

같은 화자·대본·유사 주제의 자료가 학습과 시험에 섞이지 않도록 관련 자료를 하나의 그룹으로 묶은 뒤 분리한다. 적은 자료를 잘게 나누어 시험 수만 늘리지 않는다. 수량·비율·에폭·배치 크기·학습률·학습 방식은 제공 모델과 파일럿 자료를 확인한 뒤 정한다.

최초 정면 영상 한 개는 처리 흐름과 라벨 형식을 점검하는 파일럿이다. 일반화 정확도 평가나 모델 학습에 충분한 데이터셋으로 간주하지 않는다. 원본과 미검토 자동 결과는 그대로 학습에 사용하지 않는다.

## 변환과 최적화 범위

모델·토크나이저·전후처리와 입력·출력 텐서 명세, 원본 해시 및 기준 출력을 보관한다. 공급 SDK의 지원 경로로 모델을 변환한 뒤 같은 입력으로 결과 차이와 자원 사용을 측정한다. 신규 양자화는 수행하지 않으며, 기존 공개 INT8 모델 사용과 팀의 양자화 작업 여부를 구분한다. 백엔드가 원본 정밀도를 지원하지 않으면 공급사 제공 실행물이나 지원 가능한 실행 경로를 검토한다.
