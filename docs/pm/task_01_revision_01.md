# Task 01 Revision 01 — 측정·종료·손실 처리 보완

PM 판정: CHANGES_REQUESTED. Task 02는 진행하지 않는다.

먼저 `docs/pm/task_01_environment_and_stt_poc.md`와 `docs/reports/task_01_pm_review.md`를 읽는다. 이번에는 전체 재작성이나 스택 변경 없이 Task 01의 측정과 신뢰성 결함을 수정한다. 기존 사용자의 변경과 원시 로그를 보존한다.

## 필수 수정 순서

1. **R2/R3: worker 수명과 손실 처리.** VAD flush를 마친 뒤 STT sentinel을 보내고, 큐가 일시적으로 비었다는 이유로 STT를 종료하지 않는다. worker 예외·timeout을 실행 실패로 전파한다. 입력/구간 큐 손실을 구분하여 ID·sample 구간·길이·사유를 기록한다. 암묵적 폐기 금지.
2. **R4: WAV 입력 공통화.** 원본 PCM dtype으로 정규화 후 downmix한다. wav/replay에서 같은 변환 함수를 사용한다. 미지원 형식은 명시적으로 처리한다.
3. **R1: 시간축 정정.** sample 위치를 실제 capture/replay monotonic 시간에 연결한다. VAD ready 시각을 마지막 발화 시각으로 대신 쓰지 않는다. reference annotation 없는 측정은 추정치로 표시한다. 연속 발화는 시작부터 결과 출력까지 실제 시각 차이로 계산한다. 배속 replay와 파일 직접 인식 결과를 실시간 지연 PASS에 사용하지 않는다.
4. **R6: 시험 경로 공통화.** 10분 시험이 실제 SpeechPipeline 경로를 사용하도록 한다. 종료/오류/모든 손실/큐 누적을 PASS 조건에 포함한다. current RSS와 peak RSS를 구분한다.
5. **R7: 분할 및 경계 검증.** 최대 4초 구간 요구를 실제 보장하는 방법을 구현·검증한다. soft-cut 옵션만 낮추면 보장된다고 가정하지 않는다. 오버랩을 쓰면 중복 확정 텍스트를 막고, 쓰지 않으면 경계 손실을 측정한다. 실제 단어에 걸친 절단 fixture를 사용한다.
6. **R5: 오프라인 판정 정정.** Python socket monkeypatch는 부분 smoke test로 이름을 바꾼다. 사용자 네트워크 설정은 임의 변경하지 않고, OS egress 차단 검증을 수행할 수 없으면 PARTIAL/NOT_RUN으로 남긴다.

## 함께 보완할 측정/보고

- 청크별 resampling의 경계 상태를 보존하거나 연속 resampling과 비교 검증한다.
- VAD 무음 skip과 VAD 우회 direct decode를 명시적으로 구분한다.
- CER에 합산 편집거리/합산 reference 길이를 기록하고, 공백 포함/제외 기준을 고정한다. 수치·단위·약어의 의미 보존은 별도 표시한다.
- warm-up 포함 여부, 구간 RTF/합산 발화 RTF/전체 입력 대비 계산량 비율을 구분한다.
- 고유 run_id, config, 모델 hash, revision, 오디오 식별자, 시간축 기준을 각 실행에 남긴다. 반복 실행 로그를 섞지 않는다.
- 30개 사용자 음성 부재는 NOT_RUN 유지. 기존 샘플·합성 파형·stub 검증을 사람의 실제 발표 평가로 바꾸어 보고하지 않는다.
- 보고서의 지연 PASS, 무손실 확정, RSS 불변, 완전 오프라인 증명, max_duration 3초이면 반드시 통과 등의 단정을 수정한다.

## 필수 회귀 검증

- flush가 0.3초 이상 지연되어도 마지막 구간이 정확히 1회 처리됨.
- STT worker 예외 및 timeout이 성공 종료로 보고되지 않음.
- 작은 큐 + 느린 STT에서 누락이 모두 기록되고 무손실 기준이 실패함. 입력 sample 시간축이 유지됨.
- stereo int16 입력 16384가 mono float32 0.5로 변환됨. mono/stereo int32·float도 확인.
- annotation이 있는 발화 뒤에 0.5초 이상 무음을 붙인 1배속 replay에서 종료 대기가 지연에 포함됨. 정확한 실발화 annotation이 없으면 synthetic/stub 시간축 검증임을 표시하고 실제 발화 지연 PASS로 사용하지 않음.
- 실제 강제 분할 경계에서 단어 누락/중복 평가. 기존 silence 분할 테스트와 구분.
- 수정 전후의 기존 8개 테스트 및 필요한 회귀 테스트 결과 기록.

마이크 10분 및 사용자 수동 절차는 위 결함 수정 후 수행한다. 마이크 접근/실제 발화가 불가능하면 NOT_RUN으로 남기고 사용자용 재실행 절차를 제공한다. 장시간 실행만으로 코칭 품질을 입증했다고 하지 않는다.
