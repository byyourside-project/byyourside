# Task 01 Revision 04 — 비협력적 추론 종료 처리

docs/reports/task_01_revision_03_pm_review.md를 읽고 남은 종료 문제에 집중한다. 샘플 보존 등 이미 개선한 구조는 보존하고 Task 02는 시작하지 않는다.

## 구현 범위

- 실제 STT 실행 경로를 부모가 종료·회수할 수 있는 별도 프로세스로 격리한다. 라이브러리 객체를 단순 pickle하지 말고 모델을 자식에서 초기화하고 세션 동안 재사용한다. macOS spawn 환경을 고려한다.
- deadline 발생 시 부모가 작업 취소, child terminate/필요 시 kill, join, IPC 및 logger 정리를 완료한 뒤 오류를 반환한다. 정상 종료도 잔여 요청 처리와 자원 정리 순서를 명시한다.
- timeout 후 같은 부모 프로세스에서 정상 세션을 재시작할 수 있어야 한다. 이전 worker, 출력, 로그가 새 실행에 섞이면 안 된다.
- VAD 등 다른 native 작업에도 무조건 안전하게 취소된다고 주장하지 않는다. 실제 보장 범위와 남은 제한을 구분한다.
- 닫힌 logger에 쓰기를 무시하는 것만으로 수명 관리를 대신하지 않는다.

## 완료 기준

1. 취소 신호를 전혀 확인하지 않고 대기하는 STT를 실제 프로세스 실행 경로에 주입한다.
2. 같은 부모 프로세스를 유지한 채 제한시간 내 timeout 오류를 받는다. 테스트용 전체 프로그램 sys.exit로 종료를 대신하지 않는다.
3. 살아 있는 관련 child/thread가 없고 자원이 정리됐음을 확인한다.
4. 같은 부모에서 새 정상 입력 처리가 성공함을 확인한다.
5. 기존 테스트도 재실행한다. 실제 모델 경로의 짧은 replay로 초기화·IPC 오버헤드 포함 지연을 보고한다. 테스트 실행기는 별도 외부 timeout으로 보호한다.

## 문서 및 검증 범위

- docs/reports/task_01_revision_04_report.md에 수정 파일, 실제 테스트 ID/명령/exit code, 비협력적 취소 재현, 정리 후 재실행 증거, 원시 로그를 기록한다.
- 이전 보고서의 존재하지 않는 테스트 모듈명과 실제 코드와 다른 subprocess 설명을 정정한다.
- 60초 무음 캡처는 음성 성능 NOT_RUN으로 유지한다. 30문장 CER, 600초 실제 발화, OS egress, reference annotation은 자료가 없으면 미완료로 둔다.
- 이번 짧은 종료 검증이 끝나기 전 마이크 10분 시험을 반복하지 않는다. 이전 로그를 보존하고 새 고유 run_id를 사용한다.

구현 완료 후 PM 검수를 기다린다.
