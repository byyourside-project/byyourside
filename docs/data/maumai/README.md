80행 모두 새로 작성한 **가상 예시**다. 실제 영상·음성·학습 동의·사람 검수 이력은 만들지 않았다. 23개 시나리오 그룹 단위로 분리했으며, 같은 그룹의 대조 사례는 동일 분할에 배정했다. 현재 시험 분할도 가상 자료에 대한 점검용으로, 실제 사용자 일반화 성능을 입증하는 자료가 아니다.

## 사용자 검수 순서

1. `학습데이터`의 첫 10개 예시에서 E열 입력 요약과 F열 정답 요약을 읽는다.
2. `입출력JSON`에서 같은 예시 ID의 정확한 입력·정답을 함께 확인한다. JSON 수정이 어렵다면 `학습데이터` N열 수정 메모에 의견을 남긴다.
3. 수정이 끝난 행은 I열 검수 상태, J열 검수자, K열 날짜, L열 사용 결정을 채운다. 일부만 채우면 후보가 되지 않는다.
4. `train` 행은 검수 조건 충족 시 학습후보가 되고 `validation`과 `test`는 평가전용으로 남는다.
5. 마음AI 담당자에게 기능 정의와 입력·출력 형식을 확인받은 뒤 승인된 자료만 학습 형식으로 변환한다.

엑셀의 수식은 현재 80행을 대상으로 한다. 새 행을 추가할 때는 집계 범위와 검수 수식도 늘린다. 원본과 모든 유사 변형은 같은 그룹·분할을 유지한다. 실제 자료는 화자·발표·주제의 연결 관계를 기준으로 묶는다.

## 제공 파일의 의미

- `seed_dataset.json`: 기능 정의, 공통 시스템 지시, 80개 초안, 검증 기록을 포함한다.
- `seed_dataset.csv`: 동일 초안의 행 단위 교환 파일이다.
- `draft_examples.jsonl`: system/user/assistant 메시지 형식으로 정리한 **미검수 초안**이다. 모든 행은 `training_eligible=false`다. 공급사 공식 학습 로더 호환성은 아직 확인되지 않았다.
- `validation.json`: 예시 ID, 중복 입력, 그룹 교차, 시각·근거 번호와 속도 안내 정책에 대한 구조 검사 결과다.

CSV·JSON·JSONL은 엑셀과 함께 생성한 시점의 스냅샷이다. 엑셀에서 수정·승인해도 이 파일들은 자동 변경되지 않는다. 수정된 엑셀을 기준으로 다시 내보내고 검사해야 한다. `*.jsonl`은 현재 저장소의 기본 제외 규칙에 포함되므로 Git 공유 시 추적 여부를 별도로 확인한다.

## 마음AI 형식과 현재 구현

`function`/`arguments`는 프로젝트 중간 규약이다. `<maum_0>`~`<maum_3>`는 기능 정의 시트의 제안 번호이며 실제 토크나이저에 등록되었다는 뜻이 아니다. 제공받는 function map, chat template, 종료 토큰과 모델 체크포인트에 맞춘 변환이 필요하다. 특강 자료만으로 실제 모델별 학습 명령이나 업로드 형식을 확정하지 않는다.

F01의 입력은 현재 `review_handoff.build_handoff`가 만드는 측정 근거 구조를 사용한다. F02는 현재 의미 코치의 `s/e` 의미를 따른다. 구조화된 함수 출력의 앱 연결은 후속 구현 사항이다. F03은 현재 규칙으로 처리 가능한 기능이며 LLM을 반드시 호출해야 하는 작업이 아니다. F04는 향후 Q&A의 데이터 설계로, 기능 구현 완료를 뜻하지 않는다.

이 시트는 LLM이 근거를 해석하고 답변하는 학습용이다. 얼굴 방향 측정기나 STT를 직접 재학습할 영상·음성 데이터셋을 대신하지 않는다. 실제 영상 정답에는 원본, 대본, 시간 구간, 촬영 조건, 동의 범위와 사람 검수 이력이 별도로 필요하다.

## 확인 결과와 근거

구조 검사에서 ID 중복·동일 입력 중복·그룹의 분할 교차·잘못된 구간/근거 참조는 발견되지 않았다. 기존 평가 파일 4개의 핵심 항목 88개와 새 F02 핵심 항목의 정확히 같은 문장 중복은 없었다. 의미상 유사성이나 모든 사람 정답의 정확성을 자동 검사로 보장하지 않는다. 실제 모델 평가는 실행하지 않았다.

마음AI 특강1 p.3~8의 기능 정의·인자·반환·모범 발화·평가 분리 구성을 참고했다. p.6과 p.8의 기능당 400개·평가 약 20개는 증량 참고값이며 본 80행이 그 기준을 충족했다는 뜻은 아니다. 발표에 필요한 숫자·약어·문장 경계는 보존했다. 7주차 개발 문서 가이드 §3.3~3.4의 데이터 구성·평가 전략에 대응한다.
