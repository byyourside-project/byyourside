## 2. 사용자 확인이 반영된 세 부분

사용자는 아래 세 부분에 대한 확인 요청에 "전부 대본대로 했어"라고 답했습니다. 따라서 세 표현의 차이는 사용자 확인에 근거한 STT 인식 오류로 기록합니다. 사용자 확인과 독립적인 음성 청취·단어 경계 검수는 구분하며, 자동 전사 원본은 그대로 보존합니다.

| 시각 | 대본 표현 | 자동 인식 예 | 확인용 음성 |
|---|---|---|
| 약 5~7초 | 곁이라는 발표 도우미 | 곁하는 발표 도우미 / 곁라는 발표 도 | `audio/pilot_001/review_01_intro.wav` |
| 약 43~47초 | 발표 자료 / 필요한 내용 | 발표 자리 / 대응·대용 | `audio/pilot_001/review_02_qa.wav` |
| 약 49~52초 | QCS6490 | 규씨6490 / 규시 에스 6490 | `audio/pilot_001/review_03_board.wav` |

음성 파일과 아래 데이터 파일은 분석한 PC에만 보관하며 Git 저장소에는 포함하지 않습니다. 경로는 프로젝트 폴더 기준입니다.

확인 결과: 세 부분 모두 대본대로 발화했다는 사용자 확인을 반영했습니다. 나머지 대본도 사용자 진술에 따른 참고 전사로 보관합니다. 이 샘플을 공식 STT 정확도 평가에 사용하려면 조사·어미·영문과 숫자의 실제 발음까지 독립적으로 검수해야 합니다. 현재 데이터 설계 단계에서는 같은 확인을 반복 요청하지 않습니다.

## 4. 속도 피드백의 현재 한계

자동 전사에 포함된 한글 글자는 302자이며, 처음~마지막 발화 감지 범위 54.09초로 나누면 약 335자/분입니다. 이 값은 검수되지 않은 한글 글자 수 기반 참고값입니다. 숫자·영문 약어의 실제 발음, 인식 누락, 잘못된 구간 경계가 반영되지 않아 정확한 음절 속도나 점수로 사용할 수 없습니다.

약 26.68~32.90초의 발표 전 기능 설명에는 인식된 한글 48자가 포함되어 있습니다. 구간 길이는 약 6.22초로, 상대적으로 정보가 밀집된 구간인지 검토할 후보입니다. 아직 "너무 빠름"이라는 학습 정답이나 실제 사용자 경고로 확정하지 않습니다.

1. 33.91~40.03초: 대본 진행과 계획 시간을 비교해 짧게 알려준다는 의미가 인식되었습니다. 핵심 설명 완료 / 알림 없음의 잠정 사례로 보관합니다.
