# 발표 후 리뷰와 Q&A 사용 안내

1. 기존 실행 창을 Ctrl+C로 닫고 `start_by_your_side.cmd`를 실행한다.
2. 발표 중 화면에서 대본을 준비하고 발표를 시작한다. 화면 기능만 시험하려면 직접 전사 입력을 선택한다.
3. 발표를 종료하고 저장이 끝나기를 기다린다.
4. 상단 **발표 후 리뷰 · Q&A**를 누른다. 기본 주소는 `http://127.0.0.1:8766/after`다.
5. 왼쪽 발표를 선택해 실제·목표 시간, 슬라이드별 방문 시간, 설명을 확인한 발화 근거와 다음 연습 제안을 확인한다.
6. 질문을 직접 입력하거나 **질문 녹음 → 녹음 마치기**를 누른다. 녹음은 최대 60초이며, 음성 인식이 끝나면 잘못 인식된 글자를 직접 고친다. 첫 인식은 모델 로딩 때문에 더 오래 걸릴 수 있다.
7. **관련 자료 찾기**를 누른다. 대본 핵심 문장과 직접 입력한 보충 자료에서 원문을 찾는다. 현재는 마음AI가 작성한 답변이 아니며, 관련 단어가 있는 원문이라도 질문의 정답이 아닐 수 있다.
8. 실험 결과 등 대본 밖 내용을 활용하려면 **Q&A 보충 자료 추가**에 확인된 내용을 한 줄씩 적고 저장한다.
9. 질문 이력은 발표별로 보관되며 다시 열어도 남는다. **리뷰 내려받기**로 시간·설명 근거·질문 기록을 Markdown 문서로 저장한다.

발표 녹음 중에는 질문 녹음을 시작하지 않는다. 브라우저 마이크 권한은 사용자가 질문 녹음 버튼을 눌렀을 때 필요하다. 녹음 음성은 임시 처리 후 삭제하며 인식된 질문과 검색 근거만 저장한다. 서버가 강제 종료되면 `logs/question_audio/`에 임시 파일이 남을 수 있다.

발표 기록은 `logs/presentation_sessions/`, 질문과 보충 자료는 그 아래 `qa/`에 저장한다. 질문을 저장해도 당시 발표 기록은 바꾸지 않는다. 이 폴더는 Git에서 제외되므로 다른 PC로 옮길 때 별도로 복사해야 한다. 발표 전 영상 리뷰 기록은 기존 발표 전 화면에서 연다.

마음AI SDK·모델이 제공되기 전에는 답변 생성 기능과 보드 성능을 검증할 수 없다. 카메라 방향 피드백은 영상이 있는 발표 전 리뷰에서만 제공한다.
