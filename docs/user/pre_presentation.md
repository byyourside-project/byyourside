# 발표 전 영상 연습 사용 안내

## 이 PC에서 시작하기

프로젝트 폴더의 `start_review.cmd`를 두 번 누르면 실행 창과 브라우저가 열립니다. 실행 창은 사용하는 동안 열어두고, 끝날 때 `Ctrl+C`로 종료합니다. 이미 실행 중이라는 안내가 나오면 기존 실행 창을 먼저 종료합니다.

기존 실행 방법도 같습니다: `.\.venv\Scripts\python.exe scripts/run_review.py`를 실행하고 표시된 주소를 엽니다. 설치가 필요한 다른 PC의 준비 과정은 README를 참고합니다.

## 준비할 것

- 발표 대본: TXT, MD, 텍스트가 포함된 PDF, DOCX 또는 직접 입력. HWP는 PDF나 TXT로 저장합니다. 파일 10MB, 본문 12,000자, 비교 단위 100묶음까지입니다.
- 발표 영상: MP4, MOV, WEBM, MKV, AVI, M4V. 최대 20분·500MB입니다. 기존 음성 파일도 사용할 수 있지만 시선은 분석하지 않습니다.
- 전체 목표 발표 시간: 선택 사항입니다. 목표를 지정하면 전체 발표 길이를 별도로 비교합니다.

PDF에서 추출한 줄바꿈과 읽기 순서는 입력란에서 확인합니다. 스캔 PDF는 글자를 읽을 수 없으므로 본문을 붙여 넣습니다. 대본은 비교하고 싶은 문장·내용 단위로 줄을 나눕니다.

## 촬영 방법

1. 카메라를 청중을 보는 방향, 눈높이 정면에 고정합니다.
2. 얼굴과 양쪽 눈이 보이도록 한 사람이 촬영합니다. 너무 멀리 두지 말고 상반신이 들어오도록 합니다.
3. 얼굴 앞쪽을 밝게 하고, 눈을 가리는 강한 안경 반사나 역광을 피합니다.
4. 편집으로 영상과 음성의 시점을 따로 옮기지 않습니다.

측면 촬영에서는 '청중을 잘 보고 있음'과 '카메라에서 벗어남'을 구별할 수 없습니다. 현재 기준은 정면 촬영입니다. 첫 몇 초를 자동으로 좋은 자세라고 가정하지 않습니다.

## 확인 순서

1. 영상과 대본을 올리고 대본 내용이 맞는지 확인합니다.
2. 분석 버튼을 누릅니다. 영상 준비 → 음성 분석 → 시선 분석 순서로 안내됩니다.
3. 결과에서 말하기 속도와 카메라 방향 설명을 읽고, 표시된 시간 버튼을 눌러 해당 영상을 확인합니다.
4. 전사가 틀리면 실제 들리는 말로 수정한 뒤 반영합니다. 대본으로 자동 전사를 덮어쓰지 않습니다.
5. 제목을 정해 지난 연습에서 다시 열거나 결과를 JSON으로 저장합니다.

## 결과가 의미하는 것

- **말하기 속도:** 대본과 충분히 대응하는 발화 묶음끼리 비교합니다. 자신의 다른 구간보다 25% 이상 빠르거나 느린 부분은 다시 들어볼 후보입니다. 한글 글자 수 기반이며 영문·숫자, 짧거나 불확실한 구간은 속도 비교에서 제외합니다.
- **목표 시간:** 대본 수행이 충분히 확인될 때 전체 시간과 비교합니다. 목표에 맞췄다는 것이 전달력이 좋다는 뜻은 아닙니다.
- **쉼:** 대본 묶음 안에서 긴 간격이 감지되면 표시합니다. 호흡이나 강조를 위한 쉼인지 확인해야 합니다.
- **시선:** 얼굴 방향과 눈 안의 홍채 위치를 이용한 카메라 방향 추정입니다. 실제 청중과 눈맞춤을 했는지는 측정하지 않습니다. 2초 이상 이어진 이탈 추정 구간을 표시합니다.
- **판단 보류:** 얼굴이 없거나 여러 명인 경우, 눈이 잘 보이지 않는 경우, 추정 경계에 걸리는 경우입니다. 판단 보류 시간을 시선 이탈이나 좋은 시선으로 계산하지 않습니다.

이 기준은 검토할 구간을 찾기 위한 초기 제품 설정입니다. 좋은 발표/나쁜 발표의 검증된 점수로 사용하지 않습니다. 속도가 고르게 너무 빠른 경우는 자신의 구간끼리 비교하는 방법으로는 판정할 수 없습니다.

## 실제 발표 영상 검증: 다음에 준비할 1개 파일

30~60초 영상에서 평소처럼 대본을 읽되, 정면을 보는 부분과 자료를 보기 위해 고개를 내리는 부분을 포함합니다. 어느 시점에 실제로 자료를 봤는지 사람이 표시해 자동 결과와 비교합니다. 기존 음성 녹음만으로는 시선 정확도를 검증할 수 없습니다.

현재 개발 검사는 정면 사진·얼굴 없는 화면·두 얼굴 화면으로 기능 연결과 판단 보류를 확인한 것입니다. 실제 발표자 영상에 대한 정확도·안경·고개 숙임·눈만 움직이는 경우·조명 차이는 별도 검증 항목입니다.

## 기록과 보드 적용

업로드 원본은 바꾸지 않습니다. 브라우저용 재생 영상과 분석용 음성을 별도로 만들며, 해당 재생 영상을 기준으로 피드백 시각을 계산합니다. 얼굴 좌표와 프레임을 별도 데이터셋으로 저장하지 않습니다. 녹음·영상·대본·분석 결과는 이 PC에 남습니다.

이 화면은 PC에서 검증했습니다. QCS6490와 마음AI의 실제 SDK·모델 연동 및 보드 실측은 별도 확인이 필요합니다. 모델 변환까지는 우리 범위이며 양자화 작업은 수행하지 않습니다. 자세한 연동 상태는 `docs/deployment/qcs6490.md`를 참고합니다.
