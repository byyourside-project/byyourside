# byyourside

곁 — 발표 전·중·후를 돕는 발표 도우미 프로젝트입니다. **발표 전 영상 리뷰**, **발표 중 대본 진행·계획 대비 속도 표시**, **발표 후 기록 리뷰·질문 원문 검색**을 연결했습니다. 목표 하드웨어는 QCS6490이고 마음AI 사용 계획을 유지합니다. 마음AI 답변 생성 모델과 보드 실행은 아직 연결·검증되지 않았습니다.

## 발표 전·중·후 함께 실행

Windows 프로젝트 폴더에서 최초 한 번 설치합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-app.txt
```

이후 **`start_by_your_side.cmd`를 두 번 누릅니다.** 기존 실행 창이 열려 있으면 먼저 Ctrl+C로 종료합니다.

- 발표 전: http://127.0.0.1:8765
- 발표 중: http://127.0.0.1:8766
- 발표 후: http://127.0.0.1:8766/after — 종료한 발표의 기록, 발화 근거, 보충 자료, 질문 이력과 리뷰 내려받기
- 발표 전 화면에 대본과 목표 시간을 입력하고 **이 대본으로 발표 준비**를 누르면 발표 중 준비 자료로 전달합니다. 진행 중인 발표 자료는 교체하지 않습니다.
- 상단 **발표 중 화면 열기**에서 입력 방식을 선택하고 직접 시작합니다. 마이크 없이 보려면 **직접 전사 입력 · 기능 확인**을 선택합니다.

기본 통합 실행은 모델 설치가 필요 없는 **등록 표현 비교**입니다. 인식 오타와 일반적인 바꿔 말하기에는 한계가 있습니다. 설치된 Ollama 모델을 사용하려면 다음처럼 실행합니다. 모델을 자동 설치하거나 다른 방식으로 조용히 대체하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/run_by_your_side.py --ollama-model qwen3:8b --open
```

팀원 음성 안내는 현재 **macOS `say` 전용**입니다. Windows에서는 화면 피드백을 제공하고 음성 안내 선택은 비활성화됩니다. 마음AI SDK 연결과 QCS6490 모델 변환·실행, 다른 OS의 TTS는 후속 작업입니다. 양자화 작업은 수행하지 않습니다.

자세한 흐름과 제한은 [통합 사용 안내](docs/user/pre_live_integration.md)를 참고합니다. `start_review.cmd`는 발표 전 기능만 여는 기존 실행 방법으로 유지합니다.

## 현재 가능한 기능

- MP4, MOV, WEBM, MKV, AVI, M4V 영상 분석: 최대 20분, 500MB
- TXT, MD, PDF, DOCX 대본 업로드와 수정: 최대 10MB, 본문 12,000자
- 기존 M4A, WAV, MP3 등 음성 파일 분석: 최대 20분, 80MB
- 기존 `src/vad.py`와 `src/stt.py`를 재사용한 발화 감지와 한국어 음성 인식
- 구간별 재생, 자동 전사 수정, 전사 기준의 한글 글자 수/분과 발화 사이 간격 표시
- 대본과 발화 순서 비교, 목표 시간이 있을 때 전체 발표 길이 비교
- 대본과 충분히 대응하는 발화끼리 상대 속도 비교, 긴 쉼과 다시 볼 구간 표시
- 얼굴·홍채 특징 기반 카메라 방향 추정, 지속 이탈 구간 표시와 영상 재생
- 얼굴 미검출·여러 얼굴·가림·불확실한 경우 판단 보류
- 자동 인식 원문을 보존하는 수정 기록과 JSON 결과 저장
- 이 PC에 첫 녹음 자료가 있으면 저장된 자동 전사 예제 열기
- `지난 연습` 목록에서 이전 분석 기록 다시 열기, 제목 바꾸기, 삭제

시선 기능은 실제 시선 도착점·청중과의 눈맞춤 측정이 아닌 정면 카메라 기준 추정입니다. 실제 발표 영상 정확도 검증, 마음AI SDK 연결, QCS6490 모델 변환·보드 실행은 아직 완료하지 않았습니다. 발표 중 기능은 별도 화면에서 실행하며 발표 후 Q&A는 후속 개발 범위입니다.

촬영과 사용 방법은 [발표 전 사용 안내](docs/user/pre_presentation.md), 마음AI·보드 준비 상태는 [QCS6490 적용 문서](docs/deployment/qcs6490.md)를 참고합니다.

## Windows에서 실행

Python 3.12 기준입니다. 프로젝트 폴더에서 처음 한 번 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-video.txt
.\.venv\Scripts\python.exe scripts/download_review_models.py
.\.venv\Scripts\python.exe scripts/download_gaze_model.py
```

모델 준비는 공식 sherpa-onnx와 Google 배포본을 내려받고 SHA-256을 검사합니다. 기존 STT 설정과 같은 공개 SenseVoice INT8 모델, 공개 Face Landmarker float16/v1 묶음을 그대로 사용합니다. 이 프로젝트에서 새로 양자화하는 단계는 없습니다. QCS6490용 모델 변환은 SDK와 대상 환경이 확인된 뒤 별도로 진행합니다.

이후에는 폴더의 `start_review.cmd`를 두 번 누르거나, 다음 명령으로 실행하고 표시된 주소를 엽니다.

```powershell
.\.venv\Scripts\python.exe scripts/run_review.py
```

주소: http://127.0.0.1:8765 . 서버 실행 창을 유지해야 화면을 사용할 수 있습니다. 종료는 `Ctrl+C`입니다. 포트를 바꾸려면 `--port 8766`을 붙입니다.

현재 작업 PC에는 영상 분석 의존성과 얼굴 모델까지 준비했습니다. 명령에 `--open`을 붙이면 기본 브라우저도 열립니다. `보내준 첫 녹음으로 살펴보기`는 이 PC에 있는 이전 음성 자동 인식 예제이며, 새 영상 분석과 구별됩니다. 저장된 기존 음성 기록은 그대로 다시 열 수 있습니다.

## 사용 방법과 해석

1. 영상과 대본 파일을 선택합니다. 추출된 대본 내용을 확인합니다. 목표 시간은 선택 사항입니다.
2. 대본은 비교하고 싶은 단위별로 줄을 나눕니다. 여러 줄이면 각 줄을 한 묶음으로 비교합니다. 한 줄뿐이면 마침표 등 문장 부호로 나눕니다.
3. 분석 후 피드백의 시간 버튼으로 해당 영상을 다시 봅니다. 틀린 전사를 수정하고 `수정 반영`을 누르면 속도와 대본 비교를 갱신합니다. 음성·시선 추론을 다시 실행하지 않으며 원본 자동 전사와 시선 결과를 보존합니다.
4. `대본 비교` 탭에서 연결된 구간을 듣습니다. 인식 오류나 바꿔 말하기도 있으므로 연결 실패를 실제 누락으로 확정하지 않습니다.
5. `결과 저장`으로 JSON을 내려받습니다.

속도는 전사의 한글 글자 수를 시간으로 나눈 참고값입니다. 영문·숫자의 실제 발음 길이는 세지 않습니다. 최소 3개의 비교 가능한 발화가 있을 때 자신의 다른 구간 대비 빠르거나 느린 부분을 표시하며, 좋은 발표의 절대 기준은 아닙니다. 자동 감지한 구간은 정확한 문장·호흡 경계가 아니므로 자연스럽게 끊어 말했는지 직접 들어보는 확인이 필요합니다.

시선 분석은 정면 카메라·한 사람 촬영을 기준으로 초당 2개 프레임을 처리합니다. 얼굴 방향과 눈의 위치가 2초 이상 정면에서 벗어난 것으로 보이면 재생 구간을 표시합니다. 자료나 청중을 보는 동작 자체를 잘못된 발표로 판정하지 않습니다. 미확인 구간은 정면 비율의 분모에서 제외하며, 판단 가능 시간이 부족하면 정면 비율을 제공하지 않습니다.

목표 시간 비교는 첫 발화 시작부터 마지막 발화 끝까지이며 중간 쉼을 포함합니다. 발표 중 실시간 대본 진행률 비교와는 다른 기능입니다. 전체 녹음 길이는 별도로 표시합니다. 낮은 음량은 분석용 복사본에만 최대 18dB 증폭하며 재생 파일은 원래 음량을 유지합니다.

## 코드와 기록 위치

| 위치 | 역할 |
| --- | --- |
| `src/stt.py`, `src/vad.py`, `src/config.py` | 기존 음성 인식·감지·설정 |
| `src/review_audio.py` | 파일 변환 및 기존 엔진 연결 |
| `src/review_media.py`, `src/review_script.py` | 영상 재생·분석 시계 통일, 대본 문서 읽기 |
| `src/review_analysis.py` | 속도·쉼·대본 비교 |
| `src/review_gaze.py` | 얼굴·홍채 특징의 카메라 방향 추정과 판단 보류 |
| `src/review_handoff.py` | 마음AI에 전달할 측정 근거·프롬프트 준비, 실제 호출은 미구현 |
| `src/review_worker.py`, `src/review_server.py` | 분석 작업 분리 및 로컬 화면 API |
| `src/review_db.py` | 기록 목록용 SQLite 색인 (`recordings/reviews.db`) |
| `web/` | 연습 화면 |
| `recordings/reviews/<기록 번호>/` | 업로드 원본, 재생 MP4/WAV, 자동 전사, 사용자 수정, 분석 결과 |

영상·음성과 대본은 이 PC에서 처리합니다. 로컬 서버는 `127.0.0.1`에만 열립니다. 모델 다운로드 외에 외부 AI API를 호출하지 않습니다. 원본 업로드를 유지하면서 별도 재생 MP4와 분석 WAV를 만듭니다. 얼굴 좌표·프레임은 따로 데이터셋에 저장하지 않습니다. 기록과 모델은 Git에서 제외되어 있습니다. 서버 종료 후에도 로컬 기록은 남고 `지난 연습` 목록에서 다시 열 수 있습니다. 삭제하면 해당 기록 폴더(원본·재생 파일 포함)가 지워지며 되돌릴 수 없습니다.

기록 폴더의 JSON 파일이 원본이고 `recordings/reviews.db`(SQLite)는 목록·조회용 색인입니다. 서버를 시작할 때 DB에 없는 기존 기록을 자동으로 추가하고, 폴더가 사라진 기록은 목록에서 뺍니다. DB 파일을 지워도 다음 실행 때 다시 만들어집니다.

`raw.json`의 자동 인식 원문은 수정하지 않고 `options.json`에 사용자 수정을 저장합니다. `report.json`에는 자동 구간 경계, 원문과 수정 전사, 지표와 비교 결과를 저장합니다. `training_eligible: false`로 저장하며, 검토되지 않은 결과를 학습 정답으로 자동 사용하지 않습니다.

`coaching_input.json`은 마음AI 연동에 사용할 SDK 독립적인 측정 근거와 프롬프트입니다. 대본·전사 전문, 원본 미디어, 얼굴 좌표를 포함하지 않습니다. 현재 `sdk_not_configured` 상태로 저장하며 LLM을 실행하거나 데이터를 전송하지 않습니다.

이는 기능 연결 검사입니다. 실제 발표 영상의 시선·속도 평가 정확도, 마음AI 모델 출력, QCS6490 실측 성능을 검증한 결과가 아닙니다.

기존 파이프라인의 의존성은 `requirements.txt`에 있습니다. 영상 연습 화면은 `requirements-video.txt`를 사용하며 음성·대본용 `requirements-review.txt`를 포함합니다. 기존 전체 파이프라인 회귀 검사와 마이크·보드 검증은 이번 확인 범위에 포함하지 않았습니다.
