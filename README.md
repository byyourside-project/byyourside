# byyourside

곁 — 발표 전·중·후를 돕는 발표 도우미 프로젝트입니다. 현재 첫 단계는 **녹음 파일을 분석하고 다시 들어보는 PC용 연습 화면**입니다.

## 현재 가능한 기능

- M4A, WAV, MP3 등 음성 파일 분석: 최대 20분, 80MB
- 기존 `src/vad.py`와 `src/stt.py`를 재사용한 발화 감지와 한국어 음성 인식
- 구간별 재생, 자동 전사 수정, 전사 기준의 한글 글자 수/분과 발화 사이 간격 표시
- 대본과 발화 순서 비교, 목표 시간이 있을 때 전체 발표 길이 비교
- 자동 인식 원문을 보존하는 수정 기록과 JSON 결과 저장
- 이 PC에 첫 녹음 자료가 있으면 저장된 자동 전사 예제 열기
- `지난 연습` 목록에서 이전 분석 기록 다시 열기, 제목 바꾸기, 삭제

영상·시선 분석, 발표 중 실시간 진행 피드백, Q&A 답변 보조, 마음AI LLM 연동, QCS6490 변환·실행은 후속 단계입니다. 이 화면의 실행 결과로 보드 성능을 판단할 수 없습니다.

## Windows에서 실행

Python 3.12 기준입니다. 프로젝트 폴더에서 처음 한 번 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-review.txt
.\.venv\Scripts\python.exe scripts/download_review_models.py
```

모델 준비는 공식 sherpa-onnx 배포본을 내려받고 SHA-256을 검사합니다. 기존 STT 설정과 같은 공개 SenseVoice INT8 모델을 사용하며, 이 프로젝트에서 추가 양자화를 수행하는 단계는 없습니다. 모델 변환 작업은 별도 후속 단계입니다.

이후에는 다음 명령으로 실행하고 표시된 주소를 엽니다.

```powershell
.\.venv\Scripts\python.exe scripts/run_review.py
```

주소: http://127.0.0.1:8765 . 서버 실행 창을 유지해야 화면을 사용할 수 있습니다. 종료는 `Ctrl+C`입니다. 포트를 바꾸려면 `--port 8766`을 붙입니다.

현재 작업 PC에는 가상환경과 모델을 준비했습니다. `보내준 첫 녹음으로 살펴보기`는 이전에 저장한 자동 인식 결과를 불러옵니다. 새로 인식하려면 녹음 파일을 선택하고 `녹음 분석하기`를 누릅니다.

## 사용 방법과 해석

1. 녹음 파일을 선택합니다. 대본과 목표 시간은 선택 사항입니다.
2. 대본은 비교하고 싶은 단위별로 줄을 나눕니다. 여러 줄이면 각 줄을 한 묶음으로 비교합니다. 한 줄뿐이면 마침표 등 문장 부호로 나눕니다.
3. 분석 후 구간 버튼으로 다시 듣고 틀린 전사를 수정합니다. `수정 반영`은 음성 인식을 다시 실행하지 않고 속도와 대본 비교를 갱신합니다.
4. `대본 비교` 탭에서 연결된 구간을 듣습니다. 인식 오류나 바꿔 말하기도 있으므로 연결 실패를 실제 누락으로 확정하지 않습니다.
5. `결과 저장`으로 JSON을 내려받습니다.

속도는 전사의 한글 글자 수를 시간으로 나눈 참고값입니다. 영문·숫자의 실제 발음 길이는 세지 않습니다. 최소 3개의 비교 가능한 발화가 있을 때 자신의 다른 구간 대비 빠르거나 느린 부분을 표시하며, 좋은 발표의 절대 기준은 아닙니다. 자동 감지한 구간은 정확한 문장·호흡 경계가 아니므로 자연스럽게 끊어 말했는지 직접 들어보는 확인이 필요합니다.

목표 시간 비교는 첫 발화 시작부터 마지막 발화 끝까지이며 중간 쉼을 포함합니다. 발표 중 실시간 대본 진행률 비교와는 다른 기능입니다. 전체 녹음 길이는 별도로 표시합니다. 낮은 음량은 분석용 복사본에만 최대 18dB 증폭하며 재생 파일은 원래 음량을 유지합니다.

## 코드와 기록 위치

| 위치 | 역할 |
| --- | --- |
| `src/stt.py`, `src/vad.py`, `src/config.py` | 기존 음성 인식·감지·설정 |
| `src/review_audio.py` | 파일 변환 및 기존 엔진 연결 |
| `src/review_analysis.py` | 속도·쉼·대본 비교 |
| `src/review_worker.py`, `src/review_server.py` | 분석 작업 분리 및 로컬 화면 API |
| `src/review_db.py` | 기록 목록용 SQLite 색인 (`recordings/reviews.db`) |
| `web/` | 연습 화면 |
| `recordings/reviews/<기록 번호>/` | 업로드 원본, 재생 WAV, 자동 전사, 사용자 수정, 분석 결과 |

녹음과 대본은 이 PC에서 처리합니다. 로컬 서버는 `127.0.0.1`에만 열립니다. 모델 다운로드 외에 외부 AI API를 호출하지 않습니다. 기록과 모델은 Git에서 제외되어 있습니다. 서버 종료 후에도 로컬 기록은 남고 `지난 연습` 목록에서 다시 열 수 있습니다. 삭제하면 해당 기록 폴더(원본·재생 파일 포함)가 지워지며 되돌릴 수 없습니다.

기록 폴더의 JSON 파일이 원본이고 `recordings/reviews.db`(SQLite)는 목록·조회용 색인입니다. 서버를 시작할 때 DB에 없는 기존 기록을 자동으로 추가하고, 폴더가 사라진 기록은 목록에서 뺍니다. DB 파일을 지워도 다음 실행 때 다시 만들어집니다.

`raw.json`의 자동 인식 원문은 수정하지 않고 `options.json`에 사용자 수정을 저장합니다. `report.json`에는 자동 구간 경계, 원문과 수정 전사, 지표와 비교 결과를 저장합니다. `training_eligible: false`로 저장하며, 검토되지 않은 결과를 학습 정답으로 자동 사용하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_review_*.py" -v
```

2026-10-02: 분석·API 21개 검사 통과. 실제 55.47초 M4A 파일을 새로 업로드해 발화 9개와 대본 8묶음 연결을 확인했습니다. 무음 WAV는 전사나 속도 판단 없이 처리했습니다. 이는 기능 연결 확인이며 STT 정확도 평가나 QCS6490 실측이 아닙니다.

기존 파이프라인의 의존성은 `requirements.txt`에 있습니다. 새 연습 화면은 `requirements-review.txt`만 사용합니다. 기존 전체 회귀 검사와 마이크·보드 검증은 이번 확인 범위에 포함하지 않았습니다.
