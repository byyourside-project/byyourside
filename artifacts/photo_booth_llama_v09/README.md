# Llama 3.2 사진관 학습 어댑터

**Built with Llama**

Llama 3.2 1B Instruct에 사진관 합성 명령 1,280개를 한 번 학습한 LoRA와 8개 추가 토큰의 가중치다. 원본 모델 임베딩을 제외한 학습 가중치만 포함하며, 원본 Llama 모델은 해당 계정의 승인된 Hugging Face 캐시에서 별도로 읽는다. 토큰·로그인 정보는 포함하지 않는다.

기본 모델과 리비전, 파일 해시, 검증 수치는 `MODEL_INFO.json`에 기록했다. `adapter/`와 `tokenizer/`를 함께 유지한다. 어댑터 경로에는 이 폴더 전체를 지정한다.

학습 결과를 배포용 최종 모델이나 실제 음성 인식 정확도로 해석하지 않는다. 검증 193/256(75.39%)이고, 정상 명령의 실행 보류와 배치/촬영 화면 혼동이 남아 있다. 앱은 모델이 제안한 촬영을 확인한 뒤 시작한다.
